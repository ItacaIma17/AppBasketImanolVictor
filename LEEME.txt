============================================================
  FEDERACION ARAGONESA DE BALONCESTO - APP TFG
  Instrucciones de instalacion local
============================================================

REQUISITOS PREVIOS
------------------
  - Docker Desktop (con Docker Compose)
  - Flutter SDK (Dart >= 3.9.2)
  - Git

Verificar instalaciones:
  docker --version
  docker compose version
  flutter --version


ESTRUCTURA DEL PROYECTO
------------------------
  App90/
    backend/         -> API REST (Spring Boot 3 + PostgreSQL)
    frontend/        -> App movil (Flutter)
    .env             -> Variables de entorno raiz


============================================================
  PASO 1 - BACKEND (Docker)
============================================================

1. Entrar en la carpeta del backend:

     cd backend

2. Levantar todos los servicios (BD + API + pgAdmin):

     docker compose up -d

   Esto arranca:
     - PostgreSQL 15       -> localhost:5432
     - Backend Spring Boot -> localhost:8080
     - pgAdmin 4           -> http://localhost:5050

3. Comprobar que los contenedores estan corriendo:

     docker compose ps

4. Ver logs del backend:

     docker compose logs -f backend

   Esperar a ver: "Started SatelApplication" antes de usar la app.

PARAR el backend:
     docker compose down

Parar y BORRAR datos (resetear BD):
     docker compose down -v


============================================================
  PASO 2 - FRONTEND (Flutter)
============================================================

1. Entrar en la carpeta del frontend:

     cd frontend

2. Instalar dependencias:

     flutter pub get

3. Verificar dispositivos disponibles:

     flutter devices

4. Ejecutar la app (emulador Android, iOS o Chrome):

     flutter run

   Para Chrome/web:
     flutter run -d chrome

   Para un dispositivo concreto:
     flutter run -d <device_id>

NOTA: El frontend apunta a http://localhost:8080 por defecto.
      Si se ejecuta en emulador Android fisico, cambiar la IP
      del backend en frontend/lib/services/ por la IP de tu maquina.
